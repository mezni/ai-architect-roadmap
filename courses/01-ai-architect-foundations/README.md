# Course 01 — AI Architect Foundations

The vocabulary, mental models, and decision discipline every AI architect needs
before touching RAG, agents, or platform work.

## Objectives

By the end of this course you can:

1. Define the core concepts of an AI system and place each component in an architecture.
2. Translate a vague business ask into a crisp problem statement with success metrics.
3. Propose an architecture for a typical AI workload and justify each layer.
4. Make and document design decisions using structured trade-off analysis.
5. Plan an implementation path from prototype to production.
6. Anticipate the top failure modes of AI systems and design against them.

## Prerequisites

- Software engineering fundamentals (APIs, queues, databases)
- One LLM API call's worth of familiarity (any provider)
